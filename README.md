# Сайт приглашения: Максим и Екатерина

Статичный сайт для GitHub Pages. Главная страница находится в `index.html`.

## Что заменить перед публикацией

1. Если нужно изменить анкету, в `index.html` поменяйте ссылку у кнопки анкеты.
2. Если нужно изменить карту, в `index.html` поменяйте ссылку у кнопки `Карта`.

## Публикация

Для отдельного репозитория GitHub Pages загрузите содержимое этой папки в корень репозитория:

- `index.html`
- `style.css`
- `script.js`
- папку `assets`

После этого в настройках GitHub Pages выберите публикацию из ветки `main`, папка `/root`.
